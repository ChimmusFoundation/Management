# Management

Based off the game Krazy Kingdom from Blooket

## Running the game

The game uses Python's built-in Tkinter toolkit, so it runs as a native desktop
window on macOS, Windows, and Linux desktops using X11 or Wayland:

```bash
python main.py
```

The interface includes a dashboard for state metrics, an **Events** tab with
clickable decision buttons, an **Investments** tab for delayed payoffs, and a
**History** tab for previous decisions and outcomes. No third-party GUI
packages are required.
